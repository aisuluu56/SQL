# Практикум по SQL: от первого `SELECT` до сложной аналитики

**СУБД:** PostgreSQL 14 и новее.  
**Учебная база:** «ГородМаркет», схема `training_shop`.  
**Уровень:** от нуля до продвинутого.  
**Формат:** задания без готовых решений, с нарастающей сложностью.

## 0. Подготовка

1. Создайте в PostgreSQL пустую базу `sql_practice` (через pgAdmin или запросом `CREATE DATABASE sql_practice;`, запущенным **не внутри транзакции**).
2. Подключитесь к `sql_practice`. Выполните целиком файл **`sql_practice_postgresql.sql`**. Он создаст таблицы и заполнит их тестовыми данными.
3. В начале **каждой новой сессии** выполните:

```sql
SET search_path TO training_shop, public;
```

4. Убедитесь, что таблиц **14**, а таблицы `product_reviews` **пока нет**. В базе должно быть 320 клиентов, 104 товара, 4 800 заказов и 12 000 позиций заказов.

> **Осторожно:** повторный запуск файла подготовки удаляет и заново создаёт схему `training_shop`. Все ваши изменения и созданные отзывы будут потеряны. Для практики с опасными `UPDATE` / `DELETE` используйте `BEGIN` и `ROLLBACK`.

## Справочник таблиц

| Таблица | Назначение | Важные связи |
|---|---|---|
| `branches` | Филиалы магазина | — |
| `employees` | Сотрудники, руководители, зарплаты | `branch_id → branches`, `manager_id → employees` |
| `customers` | Покупатели, города, уровни лояльности | `referred_by → customers` |
| `suppliers` | Поставщики | — |
| `categories` | Иерархия товарных категорий | `parent_id → categories` |
| `products` | Товары, цены, себестоимость, JSONB | `category_id → categories`, `supplier_id → suppliers` |
| `stocks` | Остатки по филиалам | составной ключ `(branch_id, product_id)` |
| `coupons` | Промокоды | — |
| `orders` | Заказы, статус, доставка, скидки | `customer_id`, `branch_id`, `employee_id`, `coupon_code` |
| `order_items` | Товары внутри заказов | составной ключ `(order_id, product_id)` |
| `payments` | Успешные, неуспешные и возвращённые платежи | `order_id → orders` |
| `shipments` | Курьерские отправления | `order_id → orders` (одна отгрузка на заказ) |
| `returns` | Возвраты отдельных позиций | `(order_id, product_id) → order_items` |
| `support_tickets` | Обращения покупателей | `customer_id`, `order_id`, `agent_id` |
| **`product_reviews`** | **Отзывы о товарах** | **не создана; добавите в теме 7** |

### Договорённости о расчётах

Статусы `orders.status`: `new` (новый), `paid` (оплачен), `shipped` (отправлен), `completed` (завершён), `cancelled` (отменён), `returned` (возвращён). Статусы `payments.status`: `succeeded`, `failed`, `refunded`.

Стоимость строки заказа вычисляется по формуле:

```sql
quantity * unit_price * (1 - discount_pct / 100.0)
```

Стоимость **всего заказа**: сумма строк заказа **минус** `orders.discount_amount` **плюс** `orders.delivery_fee`. Для выручки считайте только статусы заказов, указанные в задании; стоимость заказа и успешные платежи — разные показатели. Даты в исходном наборе фиксированы и не зависят от сегодняшнего дня.

## Тема 21. Транзакции и согласованность данных

## Как проходить практикум

Первые шесть тем не требуют создания таблиц или изменения данных. **Тему 7 выполняйте до темы 8**, иначе таблицы для вставок не будет. Темы 9–19 используют исходные таблицы, темы 20–24 вводят объекты SQL, а тема 25 объединяет всё изученное.

Для каждого задания сохраняйте: текст SQL-запроса, краткое объяснение логики и результат проверки (количество строк, несколько примеров или проверочное условие). Для задач с агрегатами проверяйте, не увеличилось ли число строк после `JOIN`. В задачах с изменением данных сначала пишите `SELECT` с тем же условием, а затем `UPDATE` или `DELETE`.

**Уровни:** темы 1–6 — начальный; 7–14 — базовый рабочий; 15–20 — продвинутые запросы; 21–24 — работа с PostgreSQL на практике; 25 — комплексные задания.
