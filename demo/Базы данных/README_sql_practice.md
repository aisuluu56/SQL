# Комплект «SQL с нуля до сложных запросов»

**Формат:** PostgreSQL 14+; кодировка UTF-8.

## Состав

- `sql_practice_postgresql.sql` — создаёт 14 связанных таблиц в схеме `training_shop` и автоматически заполняет их воспроизводимыми данными.
- `sql_practice_tasks.md` — 25 учебных тем, последовательные задания без решений и итоговые кейсы.
- `sql_practice_exercises_template.sql` — тот же перечень заданий в виде SQL-комментариев с местом для написания запросов в редакторе.

## Запуск

1. Создайте **пустую** базу данных `sql_practice` в pgAdmin или SQL-командой `CREATE DATABASE sql_practice;` в отдельном подключении.
2. Подключитесь к `sql_practice`.
3. Откройте `sql_practice_postgresql.sql` в Query Tool (pgAdmin) и выполните **весь** файл.
4. В конце скрипта автоматически выведется сводная таблица с количеством строк.
5. Перед работой в каждой новой вкладке Query Tool / подключении выполняйте:

```sql
SET search_path TO training_shop, public;
```

Для командной строки вместо шагов 2–3 можно выполнить:

```bash
psql -U postgres -d sql_practice -f sql_practice_postgresql.sql
```

**Важно:** повторное выполнение скрипта удалит и заново создаст схему `training_shop` (вместе с изменениями учеников).

## Отложенная таблица

`product_reviews` отсутствует **намеренно**. В теме 7 практикума обучающиеся создают её с нуля, добавляют первичный и внешние ключи, `UNIQUE`, `CHECK`, `NOT NULL`, `DEFAULT` и изменяют структуру через `ALTER TABLE`. В темах 8, 21, 23 и 24 используется эта таблица.

Для сохранения выполненных заданий создавайте отдельные `.sql`-файлы с запросами или фиксируйте запросы и результаты в отчёте. Для проверок ошибочных `INSERT` и `UPDATE` используйте отдельные команды или транзакции с точками сохранения.
