## Теория

`ft.DataTable` удобен для набора однотипных записей. Заголовки столбцов описываются через `ft.DataColumn(label=...)`, строки — через `ft.DataRow(cells=[ft.DataCell(...)])`. Количество ячеек в каждой строке должно соответствовать числу столбцов.

Таблица удобна, если важно сравнивать значения по столбцам (цена, количество, статус). Для богатого визуального каталога чаще подходят карточки. Большие таблицы нужно оборачивать в прокручиваемый по горизонтали `Row(scroll=ft.ScrollMode.AUTO, controls=[table])`.

`on_sort` у DataColumn позволяет обработать щелчок по заголовку и отсортировать исходные объекты; визуальные свойства `sort_column_index` и `sort_ascending` показывают пользователю направление. Контролы таблицы не заменяют SQL или бизнес-модель: сначала сортируются данные, затем перестраиваются строки.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    table = ft.DataTable(
        columns=[ft.DataColumn(label=ft.Text("Товар")),
                 ft.DataColumn(label=ft.Text("Количество"), numeric=True)],
        rows=[
            ft.DataRow(cells=[ft.DataCell(ft.Text("Карандаш")), ft.DataCell(ft.Text("10"))]),
            ft.DataRow(cells=[ft.DataCell(ft.Text("Блокнот")), ft.DataCell(ft.Text("4"))]),
        ],
    )
    page.add(ft.Row(scroll=ft.ScrollMode.AUTO, controls=[table]))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
