## Теория

В Flet 1.0 вкладки собираются из нескольких контролов: `ft.Tabs(length=..., content=...)`, внутри — `ft.TabBar(tabs=[ft.Tab(...)])` и `ft.TabBarView(controls=[...])`. Количество вкладок (`length`) и количество дочерних экранов должно совпадать.

Вкладки подходят для равнозначных категорий на одной странице, например «Описание», «Программа», «Отзывы». Для переходов между крупными разделами приложения лучше `NavigationBar` или маршруты. Не вкладывайте много уровней вкладок друг в друга — пользователю будет сложно понять структуру.

Каждой вкладке передайте собственный content; не пытайтесь физически переместить один и тот же control сразу в две вкладки. Если необходимо общее состояние, держите его на уровне `main`, а не внутри отдельной вкладки.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    page.add(ft.Tabs(length=2, expand=True, content=ft.Column(expand=True, controls=[
        ft.TabBar(tabs=[ft.Tab(label="Описание"), ft.Tab(label="Контакты")]),
        ft.TabBarView(expand=True, controls=[
            ft.Container(padding=20, content=ft.Text("О нас")),
            ft.Container(padding=20, content=ft.Text("Телефон: 123")),
        ]),
    ])))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
