## Теория

`ft.Row` располагает элементы в одну строку, `ft.Column` — друг под другом. В обоих случаях аргумент `controls` принимает список. Элементы можно вкладывать: например, слева от имени поставить иконку, а под именем показать описание.

Выравнивание вдоль основной оси управляется `alignment=ft.MainAxisAlignment.CENTER` (или SPACE_BETWEEN), а по поперечной — `vertical_alignment` в `Row` и `horizontal_alignment` в `Column`. `spacing` задаёт расстояние между соседними элементами. Для распределения свободного пространства используется `expand=True` у вложенного элемента.

`Row` полезен для панели кнопок, `Column` — для формы, `Row(Column(...), ...)` — для карточки товара. При переполнении ширины можно включить `wrap=True` у `Row` или перейти к адаптивной сетке, изучаемой позже.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    page.add(ft.Row(controls=[
        ft.Icon(ft.Icons.PERSON),
        ft.Column(spacing=2, controls=[
            ft.Text("Мария", weight=ft.FontWeight.BOLD),
            ft.Text("Редактор", size=12),
        ]),
    ], spacing=12))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
