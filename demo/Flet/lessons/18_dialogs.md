# 18. SnackBar и AlertDialog: обратная связь

[← Оглавление](../README.md) · [Практическое задание](../tasks/18_dialogs.py) · [Официальная документация](https://flet.dev/docs/controls/alertdialog/)

## Теория

Пользователь должен понимать, что произошло. `ft.SnackBar` — краткое уведомление внизу экрана. В Flet 1.0 его можно показать через `page.show_dialog(ft.SnackBar(ft.Text("...")))`.

`ft.AlertDialog` подходит для решения, требующего выбора: подтверждение удаления, ошибки или подробного предупреждения. Передайте заголовок, содержимое и кнопки в `actions`; после выбора закройте диалог через `page.pop_dialog()`.

Руководствуйтесь контекстом: не показывайте всплывающее окно после каждого мелкого действия; оно прерывает работу. Однако удаление данных лучше подтвердить. Сообщение должно отвечать на вопрос «что произошло/что делать дальше», а не просто «Ошибка».

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    def show_notice(e):
        page.show_dialog(ft.SnackBar(ft.Text("Изменения сохранены")))

    page.add(ft.Button("Сохранить", on_click=show_notice))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
