## Теория

`ft.ListView` выводит прокручиваемый вертикальный список: часто удобнее `Column` при большом количестве однотипных строк. Укажите `expand=True`, чтобы список занял доступную высоту в Column, а также `spacing` между строками.

`ft.GridView` выводит сетку карточек, например галерею. `runs_count` управляет числом столбцов в вертикальном режиме, `spacing` — промежутком. В обоих компонентах свойство `controls` содержит дочерние элементы.

Следите за доступной высотой: вложенная прокрутка без явных ограничений приводит к проблемам компоновки. Для простой страницы часто достаточно `page.scroll=ft.ScrollMode.AUTO`, для большого списка — отдельного `ListView(expand=True)`.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    entries = [ft.ListTile(title=ft.Text(f"Сообщение {i}")) for i in range(1, 51)]
    page.add(ft.Column(expand=True, controls=[
        ft.Text("Сообщения", size=26),
        ft.ListView(controls=entries, expand=True, spacing=4),
    ]))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
