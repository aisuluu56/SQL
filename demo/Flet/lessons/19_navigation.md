# 19. NavigationBar: переключение экранов

> Уровень: **Навигация** · Тема 19 из 28 · Цель: Разделять интерфейс на экраны через нижнюю навигацию.

[← Оглавление](../README.md) · [Практическое задание](../tasks/19_navigation.py) · [Официальная документация](https://flet.dev/docs/controls/navigationbar/)

## Теория

`ft.NavigationBar` — нижняя панель с постоянными направлениями приложения. Элементы задаются как `ft.NavigationBarDestination(icon=..., label=...)`, а текущий индекс — `selected_index`. Обработчик `on_change` позволяет получить выбранный индекс и показать нужное содержимое.

На первом этапе можно менять только содержимое центрального блока и не трогать маршрутизацию. Для этого держите переменную `selected_index`, а функцию `render()` делайте зависимой от индекса. Если у экранов общая шапка, не дублируйте её.

NavigationBar — не то же самое, что `page.views` и URL-маршруты. Первое — пользовательский элемент навигации, второе — механизм переходов и истории. Когда нужна поддержка кнопки «Назад» и адресов, переходите к маршрутам в отдельной теме.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    main_area = ft.Column(controls=[ft.Text("Главная", size=26)])

    def switch(e):
        titles = ["Главная", "Избранное", "Настройки"]
        main_area.controls = [ft.Text(titles[e.control.selected_index], size=26)]

    page.navigation_bar = ft.NavigationBar(destinations=[
        ft.NavigationBarDestination(icon=ft.Icons.HOME, label="Главная"),
        ft.NavigationBarDestination(icon=ft.Icons.FAVORITE, label="Избранное"),
        ft.NavigationBarDestination(icon=ft.Icons.SETTINGS, label="Настройки"),
    ], on_change=switch)
    page.add(main_area)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
