## Теория

Фильтрация — построение набора элементов, удовлетворяющих условию. Обычно данные в полном виде хранятся в `items`, а при каждом изменении поисковой строки создаётся новый список `filtered`. Для нечувствительного к регистру поиска используйте `query.strip().casefold()` и `name.casefold()`.

Обработчик `on_change` у TextField подходит для живого поиска. Функция `render()` должна строить карточки только по результатам фильтра, но не удалять записи из исходного списка. Пустой запрос означает «показать все».

Проверяйте два крайних случая: не найдено ни одной записи и найдено слишком много. Для пустого результата выведите понятную фразу, например «Ничего не найдено», вместо пустого белого окна.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    cities = ["Москва", "Самара", "Минск", "Казань"]
    query = ft.TextField(label="Поиск города")
    results = ft.Column()

    def refresh(e=None):
        pattern = (query.value or "").strip().casefold()
        results.controls = [ft.Text(x) for x in cities if pattern in x.casefold()]
        if not results.controls:
            results.controls = [ft.Text("Совпадений нет")]

    query.on_change = refresh
    refresh()
    page.add(query, results)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
