## Теория

Пока данные существуют только в оперативной памяти, они теряются после закрытия окна. Для небольших локальных коллекций удобен JSON: текстовый формат списков и словарей. Стандартная библиотека Python предоставляет `json.load`/`json.dump`.

При чтении проверяйте, существует ли файл, и обрабатывайте ошибку разбора `json.JSONDecodeError`. При записи используйте `encoding="utf-8"`, `ensure_ascii=False`, `indent=2`, чтобы русские символы сохранялись читаемо. Перед записью держите данные в простых Python-типах, а не в объектах Flet.

Для сохранения пользовательских данных в приложении Flet 1.0 предпочтителен каталог `FLET_APP_STORAGE_DATA` (если задан). Это служебный каталог данных; **не путайте его с временным каталогом**. В учебных заданиях используйте `Path.home() / ".flet_academy"` в качестве локального запасного пути, когда переменная окружения отсутствует.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import json, os
from pathlib import Path
import flet as ft

DATA_DIR = Path(os.getenv("FLET_APP_STORAGE_DATA") or (Path.home() / ".flet_academy"))
DATA_DIR.mkdir(parents=True, exist_ok=True)
FILE = DATA_DIR / "demo_settings.json"

def main(page: ft.Page):
    settings = json.loads(FILE.read_text(encoding="utf-8")) if FILE.exists() else {"name": "Гость"}
    name = ft.TextField(label="Имя", value=settings["name"])

    def save(e):
        FILE.write_text(json.dumps({"name": name.value}, ensure_ascii=False, indent=2), encoding="utf-8")

    page.add(name, ft.Button("Сохранить", on_click=save))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
