[← Оглавление](../README.md) · [Практическое задание](../tasks/09_boolean.py) · [Официальная документация](https://flet.dev/docs/controls/checkbox/)

## Теория

`ft.Checkbox` и `ft.Switch` имеют логическое свойство `value`: `True` или `False`. Checkbox подходит для выбора нескольких независимых вариантов, Switch — для немедленного включения настройки. `on_change` запускает реакцию при изменении.

При конструировании условий опирайтесь на bool, а не на строку «True». Если действие зависит от нескольких условий, сформулируйте правило в Python: `can_submit = accepted.value and notifications.value` (если оба нужны). Часто чекбокс согласия обязателен, а чекбокс рассылки — нет.

В интерфейсе важно не делать галочку заранее включённой, если она относится к добровольному согласию. Подписи к переключателям должны объяснять результат действия, например «Показывать подсказки».

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    alerts = ft.Switch(label="Показывать подсказки", value=True)
    info = ft.Text()

    def changed(e):
        info.value = "Подсказки включены" if alerts.value else "Подсказки отключены"

    alerts.on_change = changed
    changed(None)
    page.add(alerts, info)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
