## Теория

Элемент `ft.Button` показывает кнопку, параметр `on_click` связывает её с функцией. **Обработчик события** — функция, которая вызывается после действия пользователя. Обычно принимает один аргумент `e`: объект события; `e.control` указывает, какой элемент вызвал событие.

Не пишите `on_click=handle_click()` — это немедленный вызов при создании окна. Нужно `on_click=handle_click` без скобок. Лямбда (`lambda e: ...`) удобна для коротких действий, но длинную логику лучше вынести в функцию с понятным названием.

Изменять экран можно через уже созданные элементы (`status.value = ...`). В Flet 1.0 изменения обычно доставляются пользователю автоматически в конце обработчика. Но функцию стоит держать короткой: тяжёлые вычисления блокируют интерфейс.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    state = ft.Text("Ожидание", size=22)

    def on_start(e):
        state.value = "Работа началась"

    page.add(state, ft.Button("Начать", on_click=on_start))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
