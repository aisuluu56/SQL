## Теория

`ft.Text` выводит строку. Самые полезные аргументы: `value` (текст), `size` (размер), `color` (цвет), `weight` (толщина). У текста могут быть фиксированная ширина и выравнивание `text_align`. Для цветовой палитры используйте `ft.Colors`: например, `ft.Colors.BLUE_700` или `ft.Colors.GREY_600`.

`ft.Icon` показывает пиктограмму из набора `ft.Icons`. Иконки помогают быстро читать экран, но должны дополнять подпись, а не заменять её. Чтобы все элементы были понятны, старайтесь не использовать больше 2–3 акцентных цветов в одном небольшом блоке.

При дизайне интерфейса полезно различать смысл: заголовок (крупный и жирный), основная информация (обычный текст), второстепенная информация (небольшой серый текст). Такой подход называется **визуальной иерархией**.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    page.add(ft.Text("Погода", size=30, weight=ft.FontWeight.BOLD))
    page.add(ft.Icon(ft.Icons.WB_SUNNY, size=42, color=ft.Colors.AMBER_600))
    page.add(ft.Text("Ясно, +18 °C", color=ft.Colors.BLUE_GREY_700))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
