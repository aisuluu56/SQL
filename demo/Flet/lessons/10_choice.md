## Теория

`ft.Dropdown` позволяет выбрать один вариант из списка `options=[ft.DropdownOption(...)]`. У каждой опции есть ключ; выбранное значение читается через `dropdown.value`. В Flet 1.0 выбор обрабатывается через `on_select`, а не старый шаблон `on_change` для Dropdown. Не путайте ключ варианта и отображаемый текст.

`ft.Slider` задаёт числовой выбор в пределах `min` и `max`. Для целых значений удобно `divisions`; после движения можно обновлять подпись через `on_change`. Ползунок удобен для оценки, громкости или процента, но для точного количества товара чаще лучше поле ввода.

Выбирая элемент, отталкивайтесь от типа данных: `Checkbox` — много независимых вариантов, `Dropdown` — один из многих вариантов, `Slider` — значение в диапазоне.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    color = ft.Dropdown(label="Цвет", options=[
        ft.DropdownOption(key="red", text="Красный"),
        ft.DropdownOption(key="blue", text="Синий"),
    ])
    size = ft.Slider(min=10, max=30, value=16, divisions=10)
    result = ft.Text()

    def show(e):
        result.value = f"Цвет: {color.value}, размер: {size.value:.0f}"

    page.add(color, size, ft.Button("Применить", on_click=show), result)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
