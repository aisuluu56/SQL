## Теория

Flet — Python-библиотека для графических интерфейсов. Вы пишете Python, а Flet отображает элементы (controls) в окне или браузере. На старте не требуется HTML, CSS или JavaScript.

Входная точка — функция `main(page: ft.Page)`. `Page` представляет экран приложения и хранит заголовок, отступы, тему и размещённые элементы. `ft.run(main)` запускает приложение; круглые скобки `main()` здесь **не нужны**: передаётся сама функция.

Метод `page.add()` размещает элементы в корне страницы. `ft.Text` — простой текстовый элемент. Для удобства разработки используйте `flet run tasks/01_start.py` — Flet автоматически перезапускает приложение при сохранении файла. Для просмотра в браузере добавьте `--web`. На этом этапе все изменения статические: интерфейс задаётся кодом и создаётся при старте.

В Flet 1.0 изменения свойств элементов в обработчиках обычно применяются автоматически после завершения обработчика. Поэтому во многих современных примерах нет обязательного `page.update()`. В сложных случаях принудительное обновление остаётся возможным.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    page.title = "Мой первый экран"
    page.padding = 30
    page.add(ft.Text("Добро пожаловать!", size=26))
    page.add(ft.Text("Это первый экран на Python."))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
