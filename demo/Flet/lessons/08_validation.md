## Теория

Валидация — проверка пользовательских данных **до** их использования. Для обязательного текста удобно `strip()`, для целого числа — `int(...)` внутри `try/except ValueError`. Для дробных чисел можно использовать `float`, заранее договорившись о формате десятичного разделителя.

У `TextField` есть `error_text`: задав пояснение, вы показываете ошибку рядом с конкретным полем. После исправления ошибку следует убирать (`error_text = None`). Общие ошибки показывайте отдельным текстом или через SnackBar.

Не смешивайте проверку и обработку данных в одну длинную цепочку. Полезно написать чистую функцию `validate(...)`, которая возвращает результат/сообщение и легко тестируется без UI. Отдельно проверяйте границы, например возраст от 0 до 120, и защищайтесь от деления на ноль.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    price = ft.TextField(label="Цена, ₽")
    output = ft.Text()

    def calculate(e):
        price.error_text = None
        try:
            amount = float((price.value or "").replace(",", "."))
            if amount < 0:
                raise ValueError
            output.value = f"С НДС 20%: {amount * 1.2:.2f} ₽"
        except ValueError:
            price.error_text = "Введите неотрицательное число"
            output.value = ""

    page.add(price, ft.Button("Рассчитать", on_click=calculate), output)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
