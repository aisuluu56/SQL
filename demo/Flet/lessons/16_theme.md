## Теория

`page.theme_mode` задаёт режим темы: `ft.ThemeMode.LIGHT`, `DARK` или `SYSTEM`. Визуальную схему можно определить через `page.theme = ft.Theme(color_scheme_seed=ft.Colors.BLUE)`. Используйте тематические цвета (`PRIMARY`, `SURFACE`, `ON_SURFACE`) там, где важно соответствие режиму.

Приложение выглядит цельно, когда заголовки, кнопки и блоки подчиняются одинаковым правилам: отступы 8/16/24, два размера заголовков и ограниченная палитра. Рекомендуется выделить в модуле константы для интервалов и цветов, а повторяющиеся элементы создавать через функции.

Контрастность важнее декоративности: не используйте светло-серый текст на белом фоне для ключевой информации. Проверьте приложение в обеих темах — цвета карточек, заданные вручную, не всегда автоматически адаптируются.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    page.theme = ft.Theme(color_scheme_seed=ft.Colors.INDIGO)
    page.theme_mode = ft.ThemeMode.LIGHT
    note = ft.Text("Активная тема: светлая")

    def toggle(e):
        dark = page.theme_mode == ft.ThemeMode.LIGHT
        page.theme_mode = ft.ThemeMode.DARK if dark else ft.ThemeMode.LIGHT
        note.value = "Активная тема: тёмная" if dark else "Активная тема: светлая"

    page.add(ft.Button("Переключить тему", on_click=toggle), note)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
