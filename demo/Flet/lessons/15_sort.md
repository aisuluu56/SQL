## Теория

Сортировка меняет **порядок отображения**, а не сам смысл записей. В Python используйте `sorted(items, key=lambda item: item["price"])`. Для обратного порядка укажите `reverse=True`; исходный набор данных останется прежним.

Сортировку удобно запускать по Dropdown: пользователь выбирает «по цене»/«по названию», а обработчик вызывает одну функцию `render()` и строит список уже в правильном порядке. Если есть фильтр, последовательность обычно такая: **полные данные → фильтр → сортировка → карточки**.

Для выбора объекта храните стабильный ключ `id`, а не порядковый индекс на экране: индекс меняется после сортировки. Удаление и редактирование должны работать с исходной записью по идентификатору.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    books = [{"name": "Алгебра", "pages": 320}, {"name": "Python", "pages": 150}]
    list_box = ft.Column()

    def sort_by_size(e):
        ordered = sorted(books, key=lambda b: b["pages"])
        list_box.controls = [ft.Text(f"{b['name']}: {b['pages']} стр.") for b in ordered]

    page.add(ft.Button("Сначала короткие", on_click=sort_by_size), list_box)
    sort_by_size(None)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
