## Теория

`ft.Card` визуально отделяет блок от фона. Внутри удобно разместить `Container`, а в нём `Row`: слева `Image`, справа текстовая `Column`. Для компактных строк есть `ft.ListTile(title=..., subtitle=..., leading=...)`.

`ft.Image(src=...)` отображает изображение по URL, из файла/ресурса или из SVG-строки. Параметры `width`, `height`, `fit=ft.BoxFit.COVER` помогают контролировать размер. Для воспроизводимых локальных занятий можно вообще не зависеть от сети: используйте встроенную иконку, либо подготовленное изображение внутри каталога проекта.

Карточка должна отвечать на вопросы пользователя: **что за объект, его главное свойство, доступное действие**. Не показывайте десять равнозначных полей сразу. Во внешнем виде отделяйте второстепенные данные цветом и размером.

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    page.add(ft.Card(content=ft.Container(padding=14, content=ft.Row(controls=[
        ft.Icon(ft.Icons.HEADPHONES, size=42),
        ft.Column(controls=[ft.Text("Наушники", weight=ft.FontWeight.BOLD),
                            ft.Text("2 490 ₽")], spacing=4),
    ]))))

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
