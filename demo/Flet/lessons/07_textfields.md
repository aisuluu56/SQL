## Теория

`ft.TextField` — поле ввода. Основные параметры: `label`, `hint_text`, `value`, `multiline`, `password`, `keyboard_type`, `on_change`. Текущее значение читается как `field.value`; оно является строкой, даже если пользователь ввёл цифры.

`on_change` выполняется при изменении текста, `on_submit` — когда пользователь завершает ввод (например, Enter). Для короткой формы удобно сначала создать поле, затем использовать его значение внутри обработчика кнопки. Для поля пароля есть `password=True` и `can_reveal_password=True`.

Помните о пустой строке и пробелах: `field.value.strip()` нормализует текст. Преобразование в число (`int`, `float`) делайте только после проверки: любой пользователь может ввести «abc».

## Разбор рабочего примера

Ниже **законченный демонстрационный пример**. Его можно скопировать в отдельный файл и запустить; это **не решение** следующего задания.

```python
import flet as ft

def main(page: ft.Page):
    city = ft.TextField(label="Город", hint_text="Например, Казань")
    label = ft.Text("Введите город")

    def show_city(e):
        label.value = (city.value or "").strip() or "Город не указан"

    page.add(city, ft.Button("Показать", on_click=show_city), label)

ft.run(main)
```

**Что проверить в примере:** прочитайте код сверху вниз, найдите место создания контролов, источник данных и (если есть) обработчик события. Измените одно значение и спрогнозируйте эффект **до** запуска.
