# Flet Academy — интерактивный практикум по Flet 1.0

**28 последовательных тем · 28 Markdown-уроков · 28 самостоятельных Python-заданий.**

Курс начинается с нуля и заканчивается проектом «Сервис-деск колледжа». Теория и демонстрация находятся в `lessons/XX_name.md`, а **другая по предметной области** практическая работа — в `tasks/XX_name.py`. Стартовые задания **запускаются**, но не содержат готового решения: добавьте код в местах TODO и по требованиям.

## Быстрый старт (Windows PowerShell)

1. Установите Python 3.12 или 3.13 (Flet 1.0 поддерживает Python 3.10+).
2. Откройте терминал в папке курса и выполните:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python course_app.py
```

**Если PowerShell запрещает активацию**, используйте `.venv\Scripts\python.exe -m pip install -r requirements.txt`, затем `.venv\Scripts\python.exe course_app.py`.

В macOS/Linux вместо Windows-команды активации выполните `source .venv/bin/activate`.

## Два способа изучения

**Интерактивный режим:** `python course_app.py`. Это приложение на Flet с чтением уроков, мини-викториной, проверкой ответа, запуском задания в отдельном окне и сохранением прогресса. Кнопка «Запустить .py» запускает стартовое задание, но не выполняет его вместо ученика. Запуск отдельных окон работает в локальном desktop-режиме; для web-запуска запускайте задание из терминала.

**Обычный режим:** читайте Markdown в VS Code, изменяйте соответствующий `.py`, запускайте `flet run tasks/01_start.py`. В VS Code расширения Python и Markdown Preview помогут работать со всем курсом.

Пример:

```bash
flet run tasks/01_start.py
flet run --web tasks/01_start.py
python course_cli.py
```

## Структура

- `lessons/` — 28 самостоятельных уроков с теорией, рабочими демонстрациями и вопросами.
- `tasks/` — 28 отдельных запускаемых файлов, которые предстоит дописать.
- `course_app.py` — графическая оболочка: главы, тест, запуск задания, зачёт и **сброс прогресса**.
- `course_cli.py` — текстовое меню, если графическая оболочка недоступна.
- `curriculum.json` — структура курса и ответы для тестов.
- `teacher/` — методические рекомендации, критерии оценки и границы проекта.
- `check_course.py` — техническая проверка комплекта (синтаксис, связи, структура). **Это не автоматическая проверка выполненности заданий**.
- `progress_store.py` — сохранение отметок теста и практики, сброс темы и всего курса.
- `db/README.md`, `docker-compose.yml`, `.env.example` — запуск и настройка PostgreSQL.
- `requirements.txt` — Flet 1.0.5, Psycopg 3, python-dotenv.

## Как понять, что тема изучена

1. Прочитайте теорию и разберите демонстрацию.
2. Закройте пример и сформулируйте решение нового задания своими словами.
3. Реализуйте TODO в `tasks/XX_*.py` и самостоятельно протестируйте.
4. Ответьте на мини-вопрос в `course_app.py`; нажмите «Отметить практику выполненной», когда работа действительно готова. Прогресс — **самооценка**, код не проверяется автоматически.
5. Выполните задание со звёздочкой, если базовая работа понятна.

## Сброс прогресса и повторное прохождение

Пройденные тесты и отметки практик сохраняются в файле `~/.flet_academy/course_progress.json` на **вашем компьютере**. Кнопки работают так:

- **«Сбросить тему»** — отменяет тест и отметку о выполнении выбранного задания. Вы сможете ответить на контрольный вопрос заново и снова отметить практику.
- **«Сбросить весь прогресс»** — отменяет отметки для всех 28 тем. Обе операции требуют подтверждения.

**Важно:** сбрасываются **только отметки**, не исходный код, сделанные студентом изменения в `.py`, файл `.env` и не данные PostgreSQL. Это защищает работы от случайного удаления. Чтобы самостоятельно начать практику с чистого файла, возьмите оригинальную заготовку из архива курса. В UI кнопка автоматически становится неактивной, если отметок для сброса нет.

## Подготовка PostgreSQL (темы 26 и 28)

1. Установите Docker Desktop (если Docker не нужен, подойдёт уже установленный PostgreSQL).
2. Скопируйте `.env.example` в `.env`, измените `POSTGRES_PASSWORD` и точно такой же пароль внутри `DATABASE_URL`.
3. Выполните в корне курса `docker compose up -d`.
4. Проверьте `docker compose ps` и перейдите к [инструкции по PostgreSQL](db/README.md).

Для подключений в DBeaver/pgAdmin к базе этого **курса**: `127.0.0.1`, порт `5433`, база `flet_academy`, пользователь `flet_student`, ваш пароль из `.env`.

**Отдельный мини-практикум по Docker и Python-контейнеру** выдаётся вне курса. У него собственная база и другой порт `55432` — не путайте настройки двух проектов.

### Важное о версиях

Материалы написаны для **стабильного Flet 1.0.5 (21.10.2026)**. В поисковой выдаче часто встречаются примеры 0.x со старыми `ft.app(...)`, `ft.ElevatedButton`, `ft.dropdown.Option` и другими интерфейсами. Не смешивайте их со схемой этого курса. Зависимости зафиксированы, чтобы задания не ломались после нового релиза. API сверялся с актуальной документацией, но запуск окон Flet в среде подготовки архива технически не выполнялся.
